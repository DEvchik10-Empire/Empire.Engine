# Shaders

HLSL-исходники шейдеров движка и их сборка в SPIR-V.

## Структура

* `Hlsl/` — исходники на HLSL (это то, что правится).
* `SpirV/` — готовые `.spv` (артефакт сборки, сюда кладёт xmake).

## Сборка

```
xmake build Empire.Shaders
```

Компилятор — `glslangValidator` (HLSL-фронтенд, идёт с Vulkan SDK).
Каждый `.hlsl` собирается дважды: точка входа `mainVS` (вершина) и
`mainPS` (пиксель). Выход: `SpirV/<Имя>.vert.spv` и `SpirV/<Имя>.frag.spv`.

При сборке теста рендеринга шейдеры пересобираются автоматически
(зависимость `Empire.Shaders` в Tests/xmake.lua).

## Загрузка в рантайме

Через `Rendering::ShaderModule` (Empire.Pipeline/Vulkan/VkShader.hpp):
он просто читает `.spv` — компиляция в рантайме не производится.

Путь по умолчанию — `Shaders/SpirV` относительно корня проекта
(тест запускается оттуда же, см. `set_rundir` в Tests/xmake.lua).

## Как добавить шейдер

1. Положить `Hlsl/<Имя>.hlsl` с точками входа `mainVS` / `mainPS`.
2. Прописать имя в списке `Shaders` в `xmake.lua` этой папки.
3. Собрать (`xmake build Empire.Shaders`) и грузить `.spv` через
   `ShaderModule` + `Pipeline`.

## Текущие шейдеры

* `Sky.hlsl` — ночное небо по мотивам `sky_night-1.jpg`: индигово-синий
  градиент, луна с многослойным ореолом, редкие мерцающие звёзды (voronoi)
  и два слоя мягких облаков, подсвеченных с лунной стороны. Облака
  необъёмные: 2D-шум в проекции `dir.xz / dir.y` (крупные куски в зените,
  вытянутые полосы у горизонта), дешевле ray march'а. Полноэкранный
  треугольник, без вершинного буфера. Все цвета/яркости приходят
  push-константами (см. `SkyConstants` в Tests/Rendering/TestMain.cpp).
* `Cube.hlsl` — вращающийся куб с "дышащим" цветом и ламбертовым светом.
  Push-константы: строки матрицы MVP (float4 на строку — без сюрпризов
  упаковки float4x4), направление света + время, базовый цвет.
